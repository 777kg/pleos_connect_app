# Glossary — Pleos Connect 개발

**AccessType** — Capability 결과의 접근 수준입니다. `NONE`/`READ`/`WRITE`/`READ_WRITE`. READ 계열일 때만 조회합니다. (ch02)
**ActiveRestrictions** — `CarUxRestrictions`의 제한 비트 묶음입니다. 지역 규정은 플랫폼이 반영해서 내려줍니다. (ch03)
**AAOS Alignment** — 표준 API가 있으면 그것을 쓰고, SDK는 특화 기능만 제공한다는 정책입니다. 편입 후 최소 2개 메이저 버전까지 호환됩니다. (ch02)
**AreaBounds** — 영역별 허용 범위(min/max)입니다. null일 수 있습니다. (ch02)
**AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK** — 동시 재생(C)을 기대하는 포커스 요청입니다. 내비 안내 등에 씁니다. (ch05)
**Capability API** — `checkXxxCapabilities`. 기능 지원 여부와 범위를 확인합니다. 모든 도메인에서 먼저 호출합니다. (ch02)
**CarUxRestrictionsManager** — 주행 UX 제한을 구독하는 AAOS 서비스입니다. `registerListener`로 등록하고 `onUxRestrictionsChanged`로 받습니다. (ch03)
**CCP** — 로터리 컨트롤러입니다. 사용자 설치 앱은 지원이 선택, 기본 탑재 앱은 필수입니다. (ch04)
**CONNECT_S / CONNECT_L / CONNECT_W** — `Build.DEVICE`로 보는 플랫폼 구분값입니다. 실차에서만 유효합니다. (ch02)
**Concurrent (C)** — 포커스 공존 결과입니다. 보통 duck을 동반합니다. (ch05)
**CRN** — 예전 테스트 식별자입니다. Emulator 2.1.0부터 필요 없습니다. (ch01)
**Distraction Optimization (DO)** — 주행 중 사용 가능을 선언하는 것입니다. 선언하면 앱이 직접 기능별로 차단해야 합니다. (ch03)
**Driving view** — 화면의 고정 운전 정보 영역입니다. 앱이 가리거나 종료할 수 없습니다. (ch04)
**Duck** — 다른 소리가 날 때 볼륨을 낮추는 것입니다. 해제되면 원래 볼륨으로 복원합니다. (ch05)
**Exclusive (E)** — 새 포커스 요청이 기존 보유자를 선점하는 결과입니다. (ch05)
**기능 패리티** — 화면 방향이나 크기와 관계없이 같은 기능을 노출해야 한다는 심사 기준입니다. (ch04)
**Gleo** — 차량 음성비서입니다. VOICE_COMMAND 컨텍스트에 해당합니다. (ch05)
**Gleo Interface** — Gleo AI가 앱 기능을 호출하게 하는 규약입니다. App Schema(`assets/schema.json`), Gleo Action(Intent), Callback(`APP_ACTION_RESPONSE` broadcast)으로 이뤄집니다. (ch02)
**IVI 스크린샷** — 제출용 인포테인먼트 화면 캡처입니다. 최대 8장. (ch07)
**NaviHelper SDK** — 길안내 제어와 정보 조회 SDK입니다. 내비가 탑재된 차량에서만 동작합니다. (ch02)
**Parking / Idling / Driving** — 플랫폼이 판정하는 주행 상태 3가지입니다. (ch03)
**PERF_VEHICLE_SPEED** — 클러스터와 같은 차량 속도 프로퍼티입니다. (ch02)
**Pleos App Market Console** — 앱 심사를 제출하는 곳입니다. (ch07)
**Pleos Playground** — 계정, 프로젝트, SDK 신청 포털입니다. (ch01)
**프로젝트 ID(Key)** — 심사 제출 시 입력하는 프로젝트 식별자입니다. (ch01)
**Reject (R)** — 새 포커스 요청이 실패하는 결과입니다. 결과 중 가장 우선합니다. (ch05)
**ROTARY_SUPPORTED** — `com.hmg.rotary.ROTARY_SUPPORTED=false`로 CCP 미지원을 선언합니다. (ch04)
**Suspend** — 차량 절전 상태입니다. 진입 시 오디오를 중단, 반납, 저장, 해제합니다. (ch05)
**target_region** — `product.sw.target_region`. 값은 KOR/EUR/USA/CAN입니다. (ch02)
**Vehicle Service** — AAOS 위의 차량 서비스입니다. SDK는 IPC로 연결되므로 결과가 비동기입니다. (ch02)
**VehicleException** — `onFailed`의 예외입니다. 퍼미션 누락이면 `ERROR_SECURITY_PERMISSION`입니다. (ch02)
**Virtual Console** — 에뮬레이터에서 차량 상태와 이벤트를 주입하는 도구입니다(2.1.0 이상). (ch01, ch07)
