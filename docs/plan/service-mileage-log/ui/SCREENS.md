## 화면 흐름

1. 앱 진입→규제 확인→S05. 앱 시작 때 INFO_FUEL_TYPE 1회 조회. 허용 전·주행 규제 중에는 그림·값·조작을 숨긴다.
2. S05는 켜짐과 동력 필터를 통과한 항목을 앞→실내→바퀴→하부→뒤 순서로 좌우 열에 교대 배치한다. 열은 세로 가운데 정렬·초과 시 스크롤. 0개면 `설정에서 소모품을 켜세요`. 오른쪽 위 설정→S07, S07 뒤로→S05. EV는 내연기관 전용, 내연기관은 EV 전용을 숨기며 모름·하이브리드는 모두 보인다. 켜짐·기록은 유지.
3. portrait S05 항목 선택→S01, 1칸 뒤로→S05. landscape는 오른쪽 S01 패널을 갱신하고 2칸 뒤로 버튼은 숨긴다. S01 교체 기록→S04, 이력→S02, 기준 거리→S06. S02 뒤로→S01, S03 뒤로→S02, S06 뒤로/취소→진입 화면.
4. S02는 동력 필터에서 보이는 항목(켜짐과 무관)을 가로 스크롤 탭으로 제공한다. 2칸은 왼쪽 안내·전체 삭제/오른쪽 목록. S03은 왼쪽 조작/오른쪽 전후 비교이며 변경 저장 전 `계속 수정`/`변경 저장` 확인 대화상자를 연다. S06은 왼쪽 입력/오른쪽 안내·버튼이다.
5. S01·S05는 같은 잔여 판정이다. 유효한 현재 거리≥마지막 기록이면 경과 거리를 표시하고 기준 거리가 있으면 잔여%를 계산한다. 사진은 반올림 전 실제 잔여%에 `ceil(잔여%/10)×10`을 적용한 11단계 한 장이다. 계산 불가는 공통 벡터 `consumable_unknown`. 실제 0%에서만 전체 회색과 `설정한 거리에 도달했습니다`.
6. S02 전체 삭제는 숨긴 항목까지 모든 기록·기준 거리를 지운다. 끄기나 동력 필터는 기록·켜짐 값을 지우지 않는다. 모든 화면은 정차 중 전용이며 규제 시 값·기록·조작을 숨긴다. 크기는 비율 가정이고 실제 해상도·dp는 확인 필요.
7. Gleo `OPEN_CONSUMABLE_RECORD`는 앱을 열고 동력 방식에 맞는 전달 항목의 S01로 이동한다. 맞지 않으면 이동하지 않는다. 주행 규제 중에는 기존 규제 화면이 가린다. `GET_CONSUMABLE_STATUS`·`LIST_CONSUMABLES_BY_REMAINING`은 화면 전환 없이 음성으로만 답하며 규제 중에는 정차 후 확인을 안내한다. 세부 명세: [GLEO_ACTIONS.md](../GLEO_ACTIONS.md).
