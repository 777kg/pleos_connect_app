# S01 `알아두기` 문구 공식 출처 조사

> 2026-11-10 · 결정 9 실행 제안. 대상은 `Consumable.kt`의 18개 키와 `strings.xml`의 `tip_role_*`·`tip_late_*` 36개다. 아래 문구는 앱 반영 전 검토안이며 코드와 화면은 수정하지 않았다.

- 역할·늦어질 때의 영향은 **일반 정보**로만 쓴다. 앱의 거리·잔여%로 상태를 진단하거나 교체 시기를 권고하지 않는다. 차량 사양과 운행 조건마다 다를 수 있다.
- 근거가 특정 차종 설명서인 경우 전 차종에 동일하게 적용된다는 뜻은 아니다. 출처에 적힌 주기·거리·기간 수치는 앱 문구에 옮기지 않는다.
- `출처 없음`은 공식 자료에서 **두 문장을 함께 뒷받침할 근거를 찾지 못했다**는 뜻이다. 이 행은 `strings.xml` 현재 문구 유지 제안이며, 근거 확인 전 보강안으로 채택하지 않는다.

## 반영 전 확인 필요

- 브레이크 디스크·브레이크액·냉각수·12V 배터리의 출처는 **상태 이상**의 영향을 설명한다. 단순히 사용자가 기록한 교체 거리가 지났다는 이유로 그 상태라고 표현하지 않는다. 메인 반영 시 문구를 원인 조건이 드러나는 형태로 유지할지 확인 필요.
- `tire_rotation`·`alignment`는 교체품이 아니라 작업이다. S01의 공통 `교체가 늦어지면` 문맥과 맞는지 확인 필요.
- 출처 없음 4종은 공식 자료에서 역할과 지연 영향의 직접 근거가 확인될 때 다시 제안한다. 특히 현재 문구도 공식 근거로 검증된 상태라는 뜻은 아니다.
