## GitHub 저장소 조건
- APK는 저장소의 `apk/` 폴더, 파일명 `팀명_앱이름_release.apk`
- **실행 가능한 release 버전** — 정식 키로 서명한 `apk/bh_내차량소모품_release.apk` 준비(2026-11-10). 키·비밀번호는 저장소 밖(`C:\keys`, `~/.gradle/gradle.properties`)에만 있고 제출하지 않음
- 비공개 저장소면 공지된 심사용 GitHub 계정을 Collaborator로 초대(개인 계정은 쓰기 권한까지 주어짐). 마감 전 접근 확인
- 저장소 README.md에 쓸 것: 앱 이름과 한 줄 소개, 실행 방법, 테스트 환경과 필요한 설정, APK 위치 또는 Release 링크 → 루트 `README.md` 작성 완료(APK 위치·Virtual Console 테스트 방법 포함, 2026-11-11 갱신)
