# 소모품 교체 거리 기록

> 2026-10-28 13:09 · 상태: adopted (2026-10-28 사용자 결정). 현재 기획은 `../../service-mileage-log/PLAN.md`를 참조.

## 한 줄 소개

정차 중 소모품을 교체한 시점의 차량 누적 주행거리를 한 번 기록하고, 이후 차량 계측값으로 교체 후 경과 거리를 확인한다.

## 카테고리 · 사용 범위

- **Lifestyle / DO 미선언.** 플랫폼이 허용하는 Parking에서만 사용한다.
- 주행 규제가 적용되거나 규제 상태를 확인할 수 없으면 차량 값·기록·입력 버튼을 숨기고 조회를 멈춘다. 속도·기어로 앱이 주행 상태를 직접 판정하지 않는다.

## 핵심 기능 · API · 퍼미션

| 기능 | 후보 API·데이터 | 퍼미션 · 처리 |
|---|---|---|
| 차량 누적 주행거리 읽기 | Pleos Vehicle Odometer `DistanceDriven` 조회 | 공식 목록의 `pleos.car.permission.CAR_DRIVE` 조회. READ capability 확인 후 실제 수신값만 사용. 표준 값이면 `CarPropertyManager` 우선 검토 |
| 교체 시점 기록 | 사용자가 선택한 소모품 이름과 그때 수신한 누적 주행거리의 로컬 기록 | 차량 제어 없음. 정차 중에만 `지금 교체 기록`을 누를 수 있고, 값 조회 실패 시 저장 불가 |
| 교체 후 경과 거리 표시 | 현재 누적 주행거리 − 기록된 교체 시점 주행거리 | 현재 값과 기록 값의 단위·기준이 확인되고 두 값이 유효할 때만 계산. 재조회는 화면 진입·수동 버튼에서만 수행 |

- 소모품은 사용자가 고르는 짧은 프리셋 목록으로 시작한다. 항목별 권장 교체 주기나 정비 판정은 제공하지 않는다. 기록의 삭제·수정은 정차 중에 가능하게 한다.
- 미지원·권한 없음·조회 오류·기록 없음은 구분한다. 누적 주행거리가 이전 기록보다 작거나 값의 기준이 달라졌다면 경과 거리를 계산하지 않는다.

## 차량 앱이어야 하는 이유

사용자가 적은 교체 이력에 차량이 직접 계측한 누적 주행거리를 연결한다. 매번 계기판 수치를 외워 휴대전화에 입력할 필요 없이, 개인이 관리하려는 항목별 경과 거리를 볼 수 있다. 기본 앱이 모든 사용자 지정 소모품 기록을 지원하는지는 **확인 필요**다.

## 화면 스케치

1. **정차 중 기록 화면:** 제목 `소모품 교체 거리 기록` → 현재 차량 누적 주행거리와 갱신 시점 → 소모품별 `마지막 교체 거리 / 교체 후 경과 거리` 또는 `기록 없음` → 항목 선택 프리셋 → `지금 교체 기록`·`다시 확인`. 기록 삭제·수정은 항목의 간단한 메뉴에서 제공한다. 1칸은 세로 목록, 2칸은 넓은 목록으로 같은 기능을 둔다.
2. **주행 제한 안내:** 차량 값·기록·버튼 대신 `정차 중에만 사용할 수 있습니다`를 표시한다. 플랫폼이 앱 진입을 막으면 플랫폼 화면을 따른다.

## 위험 · 제약

- `DistanceDriven`의 단위, 누적 기준, 값 초기화·계기판 교체·차량 변경 시 동작은 API 목록만으로 확정할 수 없다. 확인 전에는 경과 거리 계산을 출시 기능으로 확정하지 않는다.
- 차종별 READ capability와 `CAR_DRIVE` 승인 여부가 다를 수 있다. 지원하지 않으면 임의 수치를 만들거나 수동 입력값으로 차량 계측값을 대체하지 않는다. 모델명으로 분기하지 않는다.
- 기기 공유 시 개인 정비 기록이 다른 사용자에게 보일 수 있다. 로컬 저장 범위·사용자 분리 가능 여부와 삭제 방법을 확인해야 한다. 백그라운드 조회·알림·계정·클라우드 동기화는 없다.
- 경과 거리는 정비 필요 시점이나 차량 안전 상태를 판정하지 않는다. 권장 교체 주기와 진단 문구는 넣지 않는다.

## MVP 크기

**중간.** 조회 한 항목, 소모품 프리셋 소수, 정차 중 기록·조회·삭제 한 화면. 로컬 저장과 값 검증이 필요하다.

## 확인 필요

- 대상 차량·에뮬레이터에서 `DistanceDriven` READ capability와 값이 제공되는지, 정확한 조회 함수·응답 단위·누적 기준.
- 같은 표준 주행거리의 `CarPropertyManager` 제공 여부 및 필요한 퍼미션. Pleos `CAR_DRIVE`의 함수별 적용과 App Market 승인 여부.
- 계기판 교체·주행거리 초기화·차량 변경 시 기록을 구분할 수 있는 공식 수단. 없으면 기존 기록과 새 값을 자동 연결하지 않는 정책.
- 공유 차량에서 로컬 기록의 사용자별 분리·삭제가 가능한지, 기본 앱의 사용자 지정 교체 기록 기능과 실제 차별점.
