S01 소모품 상세 · 잔여 거리 표시

버전 v20 · 2026-11-10 · 근거: DECISIONS.md / PLAN.md §1·§3·§4 · UI 단계: update

크기 비율 가정(1칸 360×640, 2칸 720×640). 실제 해상도·dp 확인 필요. [사진 · 단계 N%]는 사전 제작 이미지 자리표시.

범례

항목별 원본 실제 사진 1장에서 위→아래 회색 단계 11장(100·90·…·0%)을 사전 제작한다. 반올림 전 실제 잔여%에 ceil(잔여%/10)×10을 적용해 한 장을 선택한다. 예: 실제 19.4% → 단계 20% 이미지, 숫자는 19%. 실제 0%에서만 전체 회색 0% 이미지다. 공통 중립 사선 무늬 이미지 1장은 계산 불가이며 잔여율을 뜻하지 않는다. 사진이 아니며 항목은 이미지 옆 항목명·아이콘 위치로 구분한다. 실제 사진 대신 자리표시를 쓴다.
